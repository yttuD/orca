# Orcastrator

**Orquestación de agentes y desarrollo asistido, con supervisión humana.**

Orcastrator es una versión personalizada de una aplicación de escritorio Electron que integra flujos de trabajo de desarrollo, gestión de proyectos, supervisión de tareas y un motor de orquestación propio.

</div>

## Identidad

- **Nombre público:** Orcastrator.
- **Plataforma principal:** Windows Desktop. Android forma parte de la hoja de ruta.
- **Diseño:** identidad negra y verde neón; recursos aprobados de marca en el paquete oficial de iconografía de Orcastrator.
- **Seguridad:** las acciones y la recuperación del motor requieren autorización; las pantallas de diagnóstico no implican permiso de ejecución.

## Estado del desarrollo

El producto se encuentra en desarrollo y validación controlada. Las pruebas unitarias de componentes no certifican por sí solas el funcionamiento completo de la aplicación ni representan un lanzamiento listo para instalar.

## Desarrollo y pruebas

La integración de Orcastrator se realiza en ramas de desarrollo y clones de QA aislados. Se conservan rutas, esquemas, paquetes, comandos y protocolos internos heredados para mantener compatibilidad mientras la marca visible se unifica.

No utilizar los procedimientos de instalación o pruebas contra el motor operativo de Windows sin autorización específica.

## Atribuciones y licencia

Este proyecto es una personalización de software de código abierto bajo **licencia MIT**. Los derechos de autor y los avisos de atribución originales permanecen en [LICENSE](LICENSE). La identidad pública de este fork es **Orcastrator**; no implica afiliación comercial con los autores originales.

## Alcance del rebranding

El nombre, las pantallas, los textos de uso, la presentación del instalador, los accesos directos y los recursos visuales deben mostrar **Orcastrator**. Los nombres internos de repositorios, módulos, URLs de protocolo, identificadores de aplicación y rutas persistidas no se sustituyen automáticamente, ya que el cambio podría interrumpir actualizaciones y datos existentes.
